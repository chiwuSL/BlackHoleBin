# BlackHoleBin 1.0.0 安全与隐私审查

审查日期：2026-10-31。范围：当前 src/ 全部 C#，native/ 构建脚本、
C++ 渲染器、HLSL、版本资源，清单、测试、构建/发布内容。参考下载仓库
和旧版输出未并入正式包。项目不是可读取提交历史的 Git 仓库，因此
本次不包含历史提交中的密钥审计，也不是外部渗透测试或零风险认证。

## 泄露与联网结论

- 当前运行源码未发现 HTTP、Socket、遥测、自动更新、上传或第三方服务请求。
  不需要任何云 API Key。上游的更新检查、剪贴板处理和账号/终端集成未移植。
- 在项目文本中搜索常见 API Key、GitHub token、AWS access key、私钥、
  密码/secret 赋值以及 .env/.pem/.key/.pfx 等文件，未发现命中。
  该结论来自源码/文件扫描，不等同于完整网络抓包或所有编码格式的密钥检测。
- EXE/DLL 由当前源码本机构建；源代码包采用白名单复制，不打包桌面帧、
  测试保险副本、注册表导出、PDB/OBJ、参考项目 .git 或本机环境文件。
- 未发现主动外传路径；不能对操作系统、显卡驱动、第三方程序以及同用户
  已运行的恶意软件作保证。没有进行长时间网络抓包或模糊测试。

## 本地数据流

- PrintWindow 读取相交的后方窗口完整画面后裁剪，临时位图与周边缓存位于
  内存，含 CPU/GPU 副本。正式程序没有将截图/录屏保存到文件的代码。
  测试程序会输出合成背景截图用于验证，未随运行包发布。
- 保险库：%LOCALAPPDATA%\BlackHoleBin\Recovery。保存可选恢复副本及
  paths.tsv，后者的 Base64 只是编码，不是加密。副本由本机账户文件权限
  保护，不构成加密保险箱；删除原文件不代表敏感内容立即从磁盘彻底消失。
- 设置与最近撤回记录：HKCU\Software\BlackHoleBin，含文件原路径和时间。
  开机启动只使用当前用户的 Run 项，程序清单为 asInvoker，不主动提权。
- 明文副本和路径可能被同账户程序或管理员读取。保险库关闭、手工清理、
  启动清理的选项沿用原行为；启动清理会永久删除保险副本，不能撤销。

## 本次发现并修复

1. 恢复清单未验证相对项目名，可能通过 ../ 等指向保险库之外。
   现只允许六位数字项目名及明确文件/目录类型，限制清单大小，并要求
   恢复目标保险目录为 RootDirectory 的直接子目录。
2. 保险库删除前只有字符串边界校验，原路径的父目录 junction 及文件
   reparse point 也未完整拒绝。现回收、备份、恢复及清理检查路径链，
   清理前检查整个保险目录树，拒绝符号链接/junction/reparse point。
3. 递归扫描未对每个后代再次执行关键目录检查。现扫描到后代时也检查，
   且 Shell 删除前重新扫描当前项目，缩短检查到执行的时间间隔。
4. 限制托管 P/Invoke DLL 搜索到程序集目录和 System32；打开保险库使用
   Windows 目录中的明确 explorer.exe 路径。GPU 原生接口增加空指针及
   行跨度参数校验，DLL 构建启用 ASLR/NX/CFG。

既有恢复失败保留记录、临时位置提交、单实例保护、逐项回收结果确认
继续生效。功能性验证通过不代表不存在所有攻击面。

## 验证

- 安全扫描/大小与目录规则、部分恢复失败、重试、同名占用：通过。
- 清单穿越、保险目录越界、删除保险库根、父目录 junction、带链接清理：
  均被阻止；合法备份恢复：通过。
- GPU 窗口拖放事件 → 真实 Windows 回收 → STA 后台撤回：通过。
- 设置页生成测试：通过。版本资源：EXE/DLL 均为 1.0.0。

## 剩余边界

- 路径检查与 Windows 文件操作之间仍存在时间窗口。检查并非基于所有
  文件句柄的原子事务，不能承诺抵御同账户恶意进程持续竞争替换路径。
- 保险副本不是完整磁盘镜像，未验证所有 ACL、稀疏文件、EFS、ADS 等
  NTFS 特性的无损恢复；不得作为唯一备份。
- EXE/DLL 未作商业代码签名；同目录 DLL 若被替换，仍可能执行恶意代码。
  应从可信包解压使用，不要混用第三方 DLL。限定搜索路径不是签名校验。
- PrintWindow 对受保护视频或特殊 GPU 窗口可能取样失败，捕获线程也可能
  被未响应窗口拖慢。此为兼容/性能边界，未发现由此向外发送数据的代码。
- FXC 保留一条 trace 函数潜在未初始化变量警告；所有路径有显式返回，
  不改变用户认可的着色器。尚未对各厂商显卡进行完整驱动矩阵验证。
