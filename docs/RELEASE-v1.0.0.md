# BlackHoleBin 1.0.0

## 中文

首个 1.0 版本：动态黑洞与 Windows 回收站二合一，支持实时背景折射、拖动时更新、回收确认、撤回、大小上限与目录保护。无运行时网络请求。

下载 x64 ZIP，退出旧版，解压后运行 EXE，DLL 保持同目录。保险副本是本地明文文件，重要数据请独立备份。

## English

First 1.0 release: an animated desktop black hole with Windows Recycle Bin integration, live lensing during movement, confirmation, undo, size limits and folder protection. No intentional runtime networking.

Download the x64 ZIP, exit older instances, extract and run the EXE with its DLL beside it. Recovery copies are unencrypted local files; keep independent backups.

Demo media is staged and rendered with the shipped GPU shader. It does not show real private desktop content or a recorded deletion.
